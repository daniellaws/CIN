## 🛠️ Installation & Workflow Setup

To manage, test, and live-sync this project directly into your Roblox Studio environment, it is highly recommended to use **Rojo** and **Git**.

### Mobile / GitHub Web Upload
If updating directly through the GitHub mobile web portal:
1. Select **Create new file** in your repository directory root.
2. Name the file `verify_constants.py` and commit the plain-text algebraic equations.
3. Name this file `README.md` to serve as the landing page documentation for your architecture.

### Desktop Syncing via Rojo
For traditional software workflow setups mapping code into a Roblox environment container:
1. Initialize the project directory using Rojo:
   ```bash
   rojo init
   ```
2. Build or sync the current build schema into your active `.rbxl` workspace:
   ```bash
   rojo serve
   ```
